# CanonicalUnifier の重複コピー削減

## 入力と目的

ユーザ入力: `resolve` が型部分木を所有 `CanonicalTy` へ再帰コピーし、`unify` と
`unify_constructor_identity` が各子で再び解決する。深さ D の単項入れ子型では
構築・割当が概ね O(D²) になる。深さと allocation/time の伸びを比較し、overlap / 非overlap、
rigid、occurs check、ignored callable hole の判定を変えずに再コピーを減らす。

## 範囲と契約

level2。Scar の内部表現の扱いだけを変更する。言語仕様、診断、公開型、VM と schema の
バージョンは変更しない。impl overlap、constraint 証明、constructor projection の呼出側は維持する。
正本 `docs/dev/Trait_system_spec.md`、`docs/dev/テスト方針.md` と利用者向け trait 文書の意味論は維持する。

比較では変数の束縛先だけをたどり、構造の子は参照で走査する。所有木への再帰解決は
結果の取り出しと新しい変数の束縛時に限定する。束縛先は共有所有し、比較中の参照を
保ったまま後続の束縛を追加できるようにする。旧来の各階層での部分木コピー経路は削除する。

同じ型と同じ変数は成功する。異なる head / arity、rigid 変数の具体化、直接・間接の循環は拒否する。
柔軟な変数から rigid 変数への束縛は成功する。ignored callable input は有効時の右側入力の
解決済み Hole にだけ適用し、戻り値には適用しない。constructor identity の Hole は期待側だけで許容する。

## 手順と受入条件

1. crate-local テストで上記の成功・拒否境界と、単項入れ子型の割当上限を固定する。
2. 深さ 32 / 64 / 128 / 256 の一致、末端不一致、末端変数、constructor identity を修正前後で計測する。
   入力構築は計測外とし、同一条件で割当回数と経過時間を比較する。時間は揺れるため合否条件にしない。
3. 変数を含まない比較は割当不要、末端変数の比較も深さごとの再コピーを行わないことを確認する。
   一般の置換グラフ全体の線形時間やスタック深さの改善は今回の保証外とする。
4. Scar のテストと CI profile の workspace 全体検証を行う。依頼のないコミット・マージは行わない。

## 計測結果

2026-10-04、macOS arm64、rustc 1.94.1、Cargo test の unoptimized profile。
`cargo test -p scar --lib canonical_unifier -- --nocapture` で各条件を100回実行した。
同じテストと allocator で修正前後を比較し、入力構築を除き、unifier の生成・破棄を含めた。
割当は測定スレッドの System allocator に対する alloc / realloc の呼出回数。
時間は allocator の計数処理も含む参考値であり、コンパイラ全体の速度向上率ではない。

関数型の比較開始時に ignored input の位置を記録し、その後の束縛で判定が変わらないようにした。

## 検証結果

- 修正前: 判定境界2件が成功、割当上限1件が意図した失敗。
- 修正後: `cargo test -p scar --lib canonical_unifier -- --nocapture` は4件成功。
- `rtk cargo nextest run -p scar`: 372件成功（26 binaries）。
- `rtk cargo nextest run --profile ci --workspace`: 2,268件成功（56 binaries）、失敗なし。
- `cargo fmt --all -- --check`、`git diff --check`: 成功。

言語仕様の変更や未解決の実装事項はない。上記テストは実装ターンで実施した。
監査項目の更新・レポート移動・main 統合のターンでは、ユーザの指定によりテストを再実行しない。
