# 文字列の入力と表示

通常の文字列は `"..."` または `'...'` で書きます。ESCなどの制御文字は `\u{...}` で入力でき、REPLと `inspect` は文字列の内容をエスケープして表示します。

```surtr
s = "\u{1b}"
print(inspect(s ++ "a"))
print(inspect(String::codepoints(s ++ "a", StringEncoding::Utf8)))
```

出力は次のとおりです。

```text
"\u{1b}a"
Ok([27, 97])
```

引用表示だけを変えるため、文字列の内容や連結結果は変わりません。

## 入力できるエスケープ

両方の引用符で同じ規則を使います。詳しい入力規則の正本は[言語リファレンス](./language-reference.md#文字列)です。

| 入力 | 文字列に入る内容 |
|---|---|
| `\\` | バックスラッシュ |
| `\"` | 二重引用符 |
| `\'` | 単一引用符 |
| `\n` | 改行（LF） |
| `\t` | タブ |
| `\u{HEX}` | Unicodeスカラー値1文字 |
| `\#{` | 文字としての `#{` |

`HEX` は16進数1〜6桁です。大文字の数字や先頭ゼロも使えます。U+0000〜U+10FFFFを受理しますが、サロゲートのU+D800〜U+DFFFは拒否します。

```surtr
print(inspect('\u{001B}a'))
print(inspect("\u{3042}\u{1f600}"))
print(inspect("\\u{1b}"))
```

```text
"\u{1b}a"
"あ😀"
"\\u{1b}"
```

`"\u{1b}"` はESC1文字、`"\\u{1b}"` は文字としての `\u{1b}` です。`\u{...}` はUTF-8のバイト指定ではありません。たとえば `"\u{80}"` のUTF-8バイト列は `[194, 128]` です。`String::codepoints(..., StringEncoding::Utf8)` と `String::from_codepoints(..., StringEncoding::Utf8)` はUTF-8バイト列を扱います。

## 補間を文字として書く

元ソースの `#{...}` だけが補間を開始します。`\#{` で補間を抑止できます。

```surtr
name = "alice"
print("hello #{name}")
print("\#{name}")
print("\u{23}{name}")
print("#\u{7b}name}")
```

```text
hello alice
#{name}
#{name}
#{name}
```

エスケープから生成した `#` や `{` を、補間として読み直すことはありません。逆に `"\u{5c}#{name}"` は、バックスラッシュ1文字に続いて `name` を補間します。

## REPLとinspectの引用表示

引用表示では二重引用符で囲み、バックスラッシュ、二重引用符、LF、タブをそれぞれ `\\`、`\"`、`\n`、`\t` にします。その他の制御文字は `\u{...}` で表示します。対象はC0（U+0000〜U+001F）、DEL（U+007F）、C1（U+0080〜U+009F）です。

| 内容 | 引用表示 |
|---|---|
| ESCに続く `a` | `"\u{1b}a"` |
| CR／NUL／BEL | `"\u{d}"`／`"\u{0}"`／`"\u{7}"` |
| 文字としての `#{name}` | `"\#{name}"` |
| 通常のUnicode文字 | `"あ😀"` |

Unicodeエスケープの表示は小文字の16進数とし、不要な先頭ゼロを付けません。通常のUnicode文字はそのまま表示します。

**String単体の引用表示を通常の文字列式として再入力すると、元のStringになります。** List、Tuple、Result、構造体内のStringやHashMapキーにも同じ引用規則を使います。ただし `inspect` 全体を再入力可能なソースにする保証はありません。private fieldの省略やError表示などは、その値の表示契約に従います。

`print` で文字列を直接出力するときと、`to_string` が返す生の文字列には、この引用処理を加えません。`eprint(String)` は引用表示を標準エラー出力へ書き出します。内容を観察したいときは `print(inspect(value))` を使います。詳しくは[Kernel](./kernel.md#inspect)を参照してください。

## 不正なエスケープと書き換え

未知のエスケープは解析エラーです。`\q`、`\e`、`\r`、`\0`、`\x1b` は受理しません。CRは `\u{d}`、NULは `\u{0}`、ESCは `\u{1b}` と書きます。文字としてのバックスラッシュを残すには `\\` を使います。

正規表現も同じ規則です。正規表現の `\d` を渡すなら `re"\\d"` と書きます。`re"\d"` は文字列の解析時に拒否します。従来の未知エスケープを含む入力は、この表記に書き換えてください。正規表現自体の検証は[Regex](./regex.md)で説明しています。

`"\u{}"`、`"\u{xyz}"`、`"\u{000001b}"`、`"\u{110000}"`、`"\u{d800}"` なども拒否します。空白、改行、符号、`_` はUnicodeエスケープの数字内で使えません。REPLでも、Unicodeエスケープの途中で改行して次の行で完成させることはできません。

## Raw文字列と静的文字列

`"""..."""` はrawな複数行文字列です。開始行のインデントを基準に本文をdedentし、`\u{1b}` や `\q` はその表記のまま残します。raw文字列式でも既存の補間と `\#{` による補間抑止を使えます。

`@doc` の本文もrawなtriple-quoted形式です。エスケープを復号せず、補間を禁止します。

Stringパターン、includeパス、文字列を受け取る宣言引数では、通常文字列と同じエスケープ・補間開始の規則を使います。ただし、これらは静的文字列を必要とするため、元ソースの `#{...}` で始まる補間を拒否します。補間を字面として書くには `\#{` を使ってください。旧入力で静的文字列の `#{...}` をそのまま書いていた場合も、この表記に書き換えます。

| 静的文字列の入力 | 判定 |
|---|---|
| `"#{name}"` | 補間を含むため拒否 |
| `"\#{name}"` | 文字としての `#{name}` |
| `"\u{23}{name}"` | 文字としての `#{name}` |
| `"#\u{7b}name}"` | 文字としての `#{name}` |

エスケープで生成した `#{` は補間として読み直しません。`\\` や `\u{5c}` に続いて元ソースの `#{...}` を書いた場合は、補間開始が残るため静的文字列では拒否します。

開発者向けの解析・診断・引用処理の契約は[文字列リテラルの実装契約](../dev/String_literal_spec.md)を参照してください。
