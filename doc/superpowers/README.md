# 過去の設計・実装記録

このディレクトリは、各ファイルの日付時点の設計案、実装計画、作業記録を保存する場所です。
`docs/dev/README.md` の配置方針に従い、2026-10-07 に `docs/superpowers/` から移しました。

本文は当時のスナップショットです。後から変更された仕様、未採用の案、古い実行結果を含むため、
現行仕様や未完了作業の一覧としては扱いません。過去のチェックリストや失敗記録を、そのまま
現在の課題として再開しないでください。

- [設計案](specs/)
- [実装計画](plans/)
- [作業記録](records/)

移動に伴う相対リンク1件の修正を除き、資料の本文は保持しています。本文中のコード表記のパスや
コマンドは当時の記録であり、削除済みの `doc/要件定義v9.md` や移動前のパスも残しています。

現在の契約を確認する際は、[正本の案内](../../docs/dev/README.md)、
[利用者向けドキュメント](../../docs/site/README.md)、標準定義の宣言と `@doc` を参照してください。
現行挙動はソースコードと実行可能テストを優先し、未確定事項は
[open-issues.md](../open-issues.md) で確認します。
