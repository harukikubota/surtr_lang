### 今回固定する判断

- 空の `def` は compile error とする
- 空の `match` は compile error とする
- 互換レイヤー維持より、将来仕様へ寄せる破壊的変更を優先する
  既存コードに引きずられず、構文追加・ルール追加・内部表現整理を優先してよい
- `AstTy::Generic` を導入する
  `List<$A>` を含む generic 型注釈を AST で保持し、型引数を黙って捨てない
- match arm の LHS は `SafeBind.LHS` と同じ構文に寄せる
  先頭 binding は catch-all として許可し、ドキュメントも追従させる
- single quote と double quote の escape は対称にする
  差分は embedded string を展開するかどうかだけに固定する
- closure 引数型注釈は任意にする
  注釈がなくても期待型ベースで推論し、closure ごとの推論状態は外側へ mutable に汚さない
- substitution 伝播は「子 checker が成功したときだけ親へ compose する」を採用する
- 実行予算を入れるなら fuel 方式にする
- declaration index の初期収集情報は `name / kind / signature / span / module path` に固定する
- fixpoint の進捗定義は Pending 集合の減少にする
- `@@builtin` + `type` は今回の surface syntax に取り入れる
- script は「スクリプトとしても使えうる」を重視するが、非関数トップレベル定義は今回向こうに置く
- runtime error taxonomy は
  回復不能なエラーは runtime error、ユーザ制御可能な失敗は `Result`、プロセス由来の失敗は Supervisor 吸収を基本方針とする
